# Modular Tilemap Editor

언리얼/블렌더 모듈러 레벨 디자인을 위한 **882×756 그리드** 타일맵 에디터 (v0.4.11).
2D로 그린 그림을 JSON으로 저장 → Blender 스크립트가 3D 큐브로 자동 조립합니다.

**🌐 [Live Demo — 브라우저에서 즉시 사용](https://hyesunjeong.github.io/modular-tilemap-editor/)**

설치·다운로드 없이 위 URL에서 바로 그리기 시작. JSON 저장 후 Blender 단계는 아래 가이드 참고.

## ⌨️ 단축키 한눈에 보기

| 단축키 | 동작 |
|---|---|
| `1` | **선택** 도구 (사냥터 공간 선택·이동·그룹화) |
| `2` | **펜** 도구 |
| `3` | **지우개** 도구 (선택 모듈의 레이어만 지움) |
| `4` | **측정** 도구 (사각/원/경로 모드 + 영역 저장) |
| `5` | **전체 지우개** (TER·ZON 제외 모든 레이어 한 번에 지움) |
| `Shift` + 드래그 (펜/지우개) | **가로/세로 직선** — 라이브 미리보기 |
| `Shift` + 드래그 (선택) | **선택 영역 추가** (Figma식 다중 선택) |
| `Alt` + 클릭 | **스포이드** — 셀의 최상위 모듈 자동 선택 |
| `Ctrl+S` | **빠른 저장** — 첫 사용 시 저장 경로 지정, 이후 그 경로에 즉시 저장 |
| `Space` + 드래그 | 화면 이동 (패닝) |
| 마우스 휠 | 줌 인/아웃 (15% ~ 400%) |
| **휠 클릭** + 드래그 | **거리 빠른 측정** (모든 도구에서 동작, m 단위) |
| `0` | 줌 100% 리셋 |
| `[` / `]` | 브러시 크기 -1 / +1 |
| `Ctrl+Z` / `Ctrl+Y` | 되돌리기 / 다시 실행 |
| `Ctrl+G` | 그룹 토글 (선택 있으면 그룹화 / 없으면 hover 그룹 해제) |
| `Ctrl+F` | **측정 사각 자동 생성** — 선택된 블록의 bbox 크기로 측정 사각형 즉시 추가 |
| `F2` | 선택된 영역(annotation) 이름 변경 |
| **회전 핸들 드래그** | 선택된 사냥터 공간을 **프레임 중심 기준 자유 회전** (Figma 스타일, 코너 ↻ 아이콘, **항상 5도 스냅**) |
| `R` | 선택된 사냥터의 회전 **리셋 (yaw=0°)** |

브러시 프리셋 버튼: **1 / 3 / 5 / 10 / 20 / 50**

## 🗺️ 기능 한눈에 보기

| 기능 | 한 줄 요약 | 자세히 |
|---|---|---|

| **영토 잠금 🔒** | 영토 레이어를 잠가 실수 덮어쓰기 방지 | [영토 잠금](#3-영토-잠금) |

| **사냥터 회전** | 코너 ↻ 핸들 드래그로 5도 스냅 자유 회전, `R` 리셋 | [선택·그룹화](#4-사냥터-공간-선택그룹화-v044-figma-스타일) |
| **측정 도구** | 사각 · 원 · 경로 측정 저장, 이름 · 색 변경, `Ctrl+F` 자동 생성 | [측정 도구](#5-측정-도구) |
| **전체 지우개 `5`** | TER · ZON 보존, 나머지 레이어 브러시 범위 내 일괄 삭제 | [전체 지우개](#5-1-전체-지우개-단축키-5) |
| **자동 저장** | 3초 throttle로 localStorage 자동 저장, 재접속 시 복원 다이얼로그 | [자동 저장](#6-자동-저장) |
| **저장 경로 지정** | 폴더 지정 후 `Ctrl+S`로 즉시 저장, 재접속 시 경로 자동 복원 | [자동 저장](#6-자동-저장) |
| **PNG 밑그림** | 원본 크기로 좌상단 고정 오버레이, 우하단 핸들로 크기 조절(칸 스냅·비율 고정), 불투명도 조절 | [PNG 밑그림](#7-png-밑그림-underlay) |
| **Blender 연동** | JSON → Python 스크립트로 3D 큐브 목업 자동 생성 | [Blender 조립](#8-blender에서-조립) |

> **v0.4.11 변경점**
> - **그리드 확장 630×630 → 882×756** — 영토(Material 63×63) 기준 가로 14칸 × 세로 12칸, 실제 882m × 756m 커버. 비정사각 캔버스 대응(`BASE_CANVAS_W`/`BASE_CANVAS_H` 분리)
> - **밑그림 원본 크기 유지** — 불러온 이미지를 캔버스에 맞춰 자동 확대하던 동작 제거, 원본 픽셀 크기 그대로 표시. **항상 좌상단(0,0) 고정** (기존 중앙/상단 정렬 토글 제거)
> - **밑그림 크기 조절 핸들** — 우하단 청록 핸들 드래그로 크기 조절. 좌상단 고정, **가로는 그리드 칸 단위 스냅**, 세로는 원본 가로세로 비율 고정. 저장 JSON에 배율(`scale`) 포함
> - **성능 최적화 (copy-on-write)** — undo 스냅샷·직선 미리보기가 매번 전체 그리드(7레이어 × 756 × 882 ≈ 4.7M 셀)를 복제하던 것을 **행 단위 copy-on-write**로 전환. 스냅샷은 안 바뀐 행을 공유하고 변경된 행만 복제 → 스트로크당 복제량 수백 배 감소, 직선 드래그 프레임당 `structuredClone` 제거, 100단계 undo 메모리 대폭 절감
>
> **v0.4.10 변경점**
> - **지우개 모듈 단위 분리** — 같은 레이어를 공유하던 모듈도 선택한 모듈만 지워짐 (잔디↔흙↔돌바닥, 자연물↔건물 서로 영향 없음). 물은 단독 레이어 유지

> - **전체 지우개(`5`)는 영향 없음** — 모듈 구분 없이 base·environment·water·road 일괄 삭제 동작 그대로

> - **localStorage 자동 저장** — 3초 throttle, 새로고침해도 복원
> - **F2**로 영역 이름 변경
> - 패닝(스페이스+드래그), 도구 단축키(1/2/3/4/5), 영토 잠금(🔒)
> - PC **이동속도 4.2 m/s (420 cm/sec)** 기준 path ETA 계산

## 개요

모듈러 블럭(영토 마커, 잔디·흙·돌·물, 자연물, 건물, 도로, 사냥터 공간)을
2D 타일맵 형태로 그리고, Blender Python 스크립트로 3D 씬에 자동 배치합니다.

**워크플로우**:

```
[index.html에서 그리기]
        ↓ JSON 저장
[examples/*.json]
        ↓ Blender Python 실행
[3D 목업 씬]
```

## 빠른 시작

### 1. 에디터 열기
`index.html` 더블클릭. 의존성 없음, 인터넷 불필요.

### 2. 타일맵 그리기

- 좌측 팔레트에서 모듈 선택 (레이어별 그룹화)
- **좌클릭** 칠하기 / 드래그로 영역 페인트
- **우클릭** 지우개 (선택한 모듈만 지움 — 잔디 지우개는 잔디만, 흙은 흙만)
- 멀티셀 모듈(영토·도로)은 클릭 한 번에 영역 차지
- 굵은 그리드선이 **63칸마다** 표시 (Material 단위 정렬)

파일을 창에 드래그하면 자동 처리:
- `.json` → 맵 로드 (v1/구버전 ID 자동 마이그레이션)
- `.png` / `.jpg` → 밑그림 참조 이미지 로드 (모든 모듈 위에 오버레이)

### 도구 & 단축키

전체 단축키는 [상단 ⌨️ 단축키 한눈에 보기](#-단축키-한눈에-보기) 참조.

### 3. 영토 잠금
영토 위에 잔디/흙/사냥터 공간을 그릴 때, 영토가 실수로 지워지지 않도록
좌측 팔레트의 **영토 (TER)** 헤더에서 **🔒 / 🔓 토글** 가능.
잠금 ON이면 지우개가 영토 레이어를 무시 (페인트는 가능).

### 4. 사냥터 공간 선택·그룹화 (v0.4.4 Figma 스타일)

1. **선택(1)** 도구 활성
2. 드래그로 사각 영역 선택 — 사냥터 공간이 **완전히 영역 안에 들어갔을 때만** 선택됨 (10×10 단위)
3. 마우스를 떼면 노란 박스는 사라지고 **선택된 사냥터에 노란 점선 테두리만** 남음 (Figma식 강조)
4. 우측 패널에 **`사냥터 N칸`** 표시
5. **Shift+드래그**로 다른 영역을 추가 선택 (기존 선택 유지)
6. **빈 곳 드래그** → 새 사각 선택 (기존 선택 초기화)
7. 이동하려면 `Ctrl+G`로 **먼저 그룹화** (그룹마다 다른 색 외곽선)
8. 그룹된 사냥터 위 클릭+드래그 → **그룹 전체가 함께 이동** (10셀 단위 스냅)
9. 그룹된 셀 위에 hover + `Ctrl+G` → 그룹 해제

> **이동 정책**: 단순 선택 상태(노란 점선)는 시각적 강조일 뿐 이동되지 않습니다. 이동·복제 같은 변경 동작은 **명시적 그룹화(Ctrl+G) 후**에만 일어나도록 의도와 동작이 분리되어 있습니다.

### 5. 측정 도구

`4`로 진입 후 우측 패널에서 모드 선택:
- 🟦 **사각** — 대각선 + 가로×세로 + 영역 (몬스터존, 보스존)
- ⭕ **원** — 반경 + 영역 (πr²) (NPC 시선, 스킬 범위)
- 📍 **경로** — 점 클릭 누적, 세그먼트 + 총 거리 + **달리기 ETA (4.2 m/s)** + **탈것 ETA (7.5 m/s)**
- ✋ **이동** — 저장된 영역 선택 후 드래그로 이동

또한 모든 도구에서 **마우스 휠 버튼 클릭+드래그**로 임시 거리 측정선(시안색)을 띄울 수 있습니다. 떼면 사라집니다.

라벨 입력 후 **영역 저장** → 캔버스에 **색깔 박스 + 라벨** 표시.
`라벨 크기` 슬라이더로 **12~40px 사이 조정** (기본 22px, sans-serif).
이동 모드에서 영역 선택 후 `F2` → 라벨 변경.

### 5-1. 전체 지우개 (단축키 5)

영역을 깔끔하게 비우고 다시 그릴 때 사용:
- 📌 **영토(TER)**·**사냥터(ZON)**는 그대로 보존
- 🧹 base·elevation·environment·road 레이어를 **브러시 크기 영역 안에서 한 번에 지움**
- 🟧 커서가 **주황 점선 사각형**으로 표시되어 일반 지우개(빨강)와 구분

### 6. 자동 저장

- 마지막 변경 **3초 후 자동 저장** (브라우저 localStorage)
- 상태바에 `💾 자동 저장됨 HH:MM:SS` 표시
- 페이지 새로고침/크래시 후 다음 접속 시 **복원 다이얼로그** 표시
- 중요한 단계마다 **수동 JSON 저장**(다운로드) 백업 권장 (브라우저 캐시가 지워져도 파일은 남음)

### 7. PNG 밑그림 (Underlay)

언리얼 엔진의 네비게이션 영역을 스크린샷으로 캡쳐 → PNG 저장 →
에디터의 **이미지 불러오기** 또는 드래그-앤-드롭으로 로드.
**모든 모듈 위에 오버레이**되며 투명도 슬라이더(0~100%)로 조절.
이미지는 **원본 픽셀 크기 그대로, 항상 좌상단(0,0)에 고정**되어 표시됩니다.
우하단 **청록 핸들을 드래그**하면 크기를 조절할 수 있으며, 이때 **가로 폭은 그리드 칸 단위로 스냅**되고 세로는 원본 가로세로 비율이 유지됩니다(좌상단 고정). 배율은 JSON에 `scale`로 저장됩니다.

### 8. Blender에서 조립

1. Blender 실행 (4.x 권장)
2. **Scripting** 탭 → 새 스크립트 → `blender_scripts/assemble_mockup.py` 내용 붙여넣기
3. 스크립트 상단의 `JSON_PATH` 변수를 본인 JSON 경로로 수정
   ```python
   JSON_PATH = r"C:\path\to\your\tilemap.json"
   ```
4. `Alt+P` 로 실행

→ 색상 큐브로 3D 목업 자동 생성. 탑다운 ortho 카메라 + 광원 자동 셋업.
F12로 렌더 가능.

## JSON 포맷 (v2)

```json
{
  "version": 2,
  "size": [882, 756],
  "tile_size_m": 1.0,
  "coord_system": {"origin": "top-left", "x_axis": "right", "y_axis": "down", "z_axis": "up"},
  "modules_legend": [...],
  "placements": [
    {"module": "TRN_Base_Grass", "x": 0, "y": 0, "z": 0, "footprint": [1,1], "yaw": 0, "groupId": null}
  ],
  "annotations": [...]
}
```

- 좌표: 이미지 기준 (좌상단 (0,0), x→오른쪽, y→아래)
- `z`는 높이 레이어 인덱스 (생략시 0)
- `groupId`: 사냥터 공간 그룹 ID (null이 아닌 경우 그룹 소속)
- Blender 변환 시 y축이 반전되어 월드 +Y(북쪽) = 타일맵 위쪽으로 매핑

**자동 마이그레이션**: `block_1m_*`, `tree`, `building_3x3`, `ENV_Tree_Pine`,
`BLD_House_Generic`, `TER_Material` 등 구 ID가 새 ID로 자동 변환.

### 레이어 스택 (아래 → 위)

```
territory → base → elevation → environment → road → zone
```

- **territory**: 영토 마커 (지면 아래, 잠금 가능)
- **base**: 지형 (잔디/흙/돌/물)
- **elevation**: (현재 비어있음, 향후 단차/슬로프용)
- **environment**: 자연물/건물
- **road**: 도로
- **zone**: 사냥터 공간 (모든 것 위)

### 모듈 추가/변경

세 곳을 동기화:

1. `index.html` 의 `MODULES` 배열 (색·이름·footprint·layer·snap·pattern)
2. `blender_scripts/assemble_mockup.py` 의 `MODULE_STYLE` (3D 높이·색)
3. 새 카테고리 prefix는 Blender의 `get_module_layer()` + `LAYER_Z_OFFSET`에도 추가

## 디자인 의도

**왜 큐브로 시작하는가**: 진짜 모듈 메쉬를 바로 쓰면 결과가 이상할 때
"좌표 버그인지, 모듈 자체 문제인지" 분간이 안 됩니다. 단순 색상 큐브로
먼저 데이터 파이프라인(JSON 파싱 → 좌표 변환 → 배치)을 격리해서 검증한 뒤,
나중에 한 줄만 바꿔 실제 모듈 라이브러리로 교체하는 흐름입니다.

```python
# 지금: 큐브 생성
mesh = make_cube_mesh(...)

# 나중에: 라이브러리에서 진짜 모듈 가져오기
mesh = append_from_library("modules.blend", "SM_Tree_Pine_A")
```
